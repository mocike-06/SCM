ESP32 GPIO 控制：点亮 LED 与按键输入

系列：ESP32 入门 更新：2026-10-25

掌握 ESP32 最基础的 IO 能力：用 pinMode / digitalWrite 驱动板载与外部 LED，用 INPUT_PULLUP 读取一个独立按键。本讲从零讲清 OUTPUT/INPUT 是什么、内部上拉怎么用、为什么 ESP32 只认 3.3V、以及哪些引脚不能乱接，为后续所有外设打下地基。

一、本课目标与前置知识

学完本课你能做到：

  • 看懂 setup() / loop() 结构，会用 pinMode、digitalWrite、digitalRead 三个函数。
  • 独立接线：外部 LED（带限流电阻）和按键（用内部上拉，不用外部电阻）。
  • 避开 ESP32 的「坑引脚」（GPIO6-11 禁用、GPIO0/2/15 影响启动），会选安全引脚。

需要提前掌握的前置知识（对应学习路线阶段 4~5 前两篇）：

  • STM32 或 51 的 GPIO 概念（阶段 2/4）：高低电平、输出/输入、按键抖动——ESP32 里思路完全一样，只是 API 换成 Arduino 风格。
  • 环境搭建（esp32-env.html）：Arduino IDE 装好 ESP32 开发板包、能烧录、会开串口监视器。
  • C 语言基础（阶段 1）：变量、if 判断、函数定义。

本课会出现的新名词（下面逐一讲解）：GPIO、pinMode / digitalWrite / digitalRead、INPUT_PULLUP、3.3V 电平、LED_BUILTIN、启动引脚（GPIO0/2/15）、按键抖动。

二、基础概念铺垫

1. GPIO 与方向配置：pinMode

生活类比：GPIO 引脚像一个双通道对讲机，同一个孔既能「喊话」也能「听声」，但用之前必须先拨开关选好今天是当喇叭（输出）还是当麦克风（输入）。

一句话定义：pinMode(引脚号, 模式) 把某个 GPIO 引脚配置成指定方向，模式用 OUTPUT（输出）或 INPUT（输入）等常量。

例子：pinMode(4, OUTPUT) 把 GPIO4 配成输出，之后才能用 digitalWrite 驱动 LED。

2. 输出电平：digitalWrite 与 HIGH / LOW

生活类比：digitalWrite 像拉开关——拉上（HIGH）电灯亮，拉下（LOW）电灯灭。

一句话定义：digitalWrite(引脚, HIGH) 让引脚输出高电平（ESP32 为 3.3V），digitalWrite(引脚, LOW) 输出低电平（0V）。

例子：digitalWrite(4, HIGH) 后 GPIO4 对外是 3.3V，外接 LED 亮；写 LOW 灭。注意：输出高电平只有 3.3V，不是 5V，直接驱动 5V 外设会损坏引脚。

3. 读输入：digitalRead 与悬空问题

生活类比：一根悬空的绳随风乱摆——引脚处于输入且没接任何东西时，电压是「浮空」的，读出来一会 1 一会 0，完全随机。

一句话定义：digitalRead(引脚) 返回该引脚当前电平（HIGH 或 LOW）；输入引脚必须有确定的电平来源，否则结果不可信。

例子：按键一端接引脚、另一端接 GND，引脚平时被上拉为 HIGH，按下被短接到 GND 变 LOW，digitalRead 才能稳定读到两种确定状态。

4. 内部上拉：INPUT_PULLUP

生活类比：上拉电阻像给悬空绳子加一根「默认拉向上方」的橡皮筋——没人拽它时它稳稳在高处，有人拽（按键接地）才下来。

一句话定义：pinMode(引脚, INPUT_PULLUP) 在芯片内部给引脚接一个约 45kΩ 的电阻到 3.3V，让引脚默认电平为高，省掉外部电阻。

例子：pinMode(15, INPUT_PULLUP) 后，GPIO15 未按下时读到 HIGH，按下接地时读到 LOW。如果用普通 INPUT（浮空），读数会乱跳。

5. 启动引脚避坑：GPIO6-11、GPIO0/2/15

生活类比：有些引脚是「多面手」，出厂就兼职别的工作——你把它们接外设，相当于让值班员同时干两份活，上电时就会出错。

一句话定义：ESP32 的 GPIO6~GPIO11 被内部 Flash 芯片占用，严禁外接；GPIO0、GPIO2、GPIO15 与启动模式（下载模式选择）有关，烧录时若外接强驱动设备可能导致无法进入下载、反复重启。

例子：本课选 GPIO4（LED）和 GPIO15（按键）作为演示引脚；GPIO15 属于启动相关引脚，做输入（高阻、靠上拉）通常没大问题，但若烧录异常，先拔掉 GPIO0/2/15 上的外设再烧。更稳的选择是 GPIO4 / GPIO16 / GPIO17。

6. GPIO 矩阵 vs IO_MUX：为什么 ESP32 引脚「怎么引都行」

生活类比：老款单片机（51）像固定工位流水线，每个外设的线只能焊死在指定引脚上；ESP32 像一台电话交换机——内部有一张「GPIO 矩阵（GPIO Matrix）」开关网络，你想把任意外设信号接到任意空闲引脚，都能在软件里配通。

一句话定义：ESP32 的引脚路由分两条路——IO_MUX 是固定功能的快速通道（某引脚原生就是某外设脚，路径最短、延迟最低）；GPIO Matrix 是可任意映射的交换矩阵，能把任何外设输入/输出信号接到任何 GPIO。Arduino 的 pinMode / digitalWrite 默认走 GPIO Matrix。

例子：你可以把 LEDC PWM 输出绑到 GPIO4（ledcAttachPin(4,0)），也可以绑到 GPIO16——这就是 GPIO Matrix 在起作用；而 UART 的 TX/RX 走 IO_MUX 高速通道时最稳，所以串口默认固定在 GPIO1/GPIO3。

三、原理介绍

ESP32 的每个 GPIO 引脚内部都是一组可配置的模拟开关：设成输出时接到「推挽驱动器」，设成输入时驱动器断开、变成高阻探头。理解这两层电路，才能解释「为什么按键悬空会乱跳、为什么要用 INPUT_PULLUP、为什么 GPIO2 上电瞬间不能乱接」。

一次按键控制 LED 的完整链路：pinMode 配置方向 → 内部寄存器把引脚接到推挽驱动器或高阻态 → loop 里 digitalRead 读电平、digitalWrite 改变输出。

原理 1：推挽输出——为什么 digitalWrite 能稳稳点亮 LED

「推挽」是一对互补 MOS 管：上管（PMOS）把引脚连到 3.3V，下管（NMOS）把引脚连到 GND。digitalWrite(HIGH) 只开上管、digitalWrite(LOW) 只开下管——任何时刻引脚都被有源地连到某个电平，输出电阻只有几十 Ω，所以即使串了 LED 限流电阻也能稳稳驱动。对比：如果两个管子都关（高阻态），引脚电平就「飘」了——那就是输入态。

关键数值：ESP32 GPIO 高电平 = 3.3V（不是 5V！），每脚最大输出/吸收电流约 12mA——这就是为什么 LED 要串 220~330Ω 限流电阻、为什么 GPIO 不能直接驱动继电器/电机（得加三极管或光耦）。

原理 2：高阻输入与上拉电阻——为什么悬空电平会乱跳

设成 INPUT 后，两个 MOS 管都关，引脚变成高阻态（几乎不取电流），内部只接一个电压比较探头去读电平。问题来了：高阻引脚什么都不接时，周围的电磁干扰、人体感应会在引脚上感应出随机电压——探头读到的就是忽高忽低的噪声，这叫「浮空」。

上拉电阻的实质：在引脚与 3.3V 之间接一颗几十 kΩ 电阻，把悬空电平强行拉到确定的高电平；按键另一端接 GND，按下时才把引脚「拽低」。ESP32 内部集成了约 45kΩ 的可编程上拉，pinMode(btnPin, INPUT_PULLUP) 就是把它打开——所以本课按键不用外接电阻。这解释了为什么按下是 LOW：内部上拉平时维持 HIGH，按下接通 GND 才变 LOW。

原理 3：启动引脚——为什么 GPIO0/2/15 上电瞬间不能乱动

ESP32 上电时，ROM Bootloader 要靠几个引脚的上电电平决定启动模式：GPIO0 低 = 下载模式、高 = 正常启动；GPIO2、GPIO15 等也会被采样。这些脚内部只是弱上拉/下拉，若外接电路在程序跑起来之前就把电平拉偏（比如 LED 一直拉低），芯片可能误进下载模式或启动异常。这就是避坑表「避开 GPIO0/2/15、GPIO6~11」的根因——不是它们不能用，而是上电那一瞬间外部不能改变其电平；程序跑起来之后再用通常没事。

记忆点：输出=推挽（上管接3.3V/下管接GND，有源驱动，3.3V/12mA）；输入=高阻探头，悬空必乱飘；上拉=把悬空强拉到高电平（内部45kΩ）；GPIO0/2/15/6~11 是启动/Flash 引脚，上电瞬间别接电路。

四、硬件接线说明

除板载 LED 外，再外接一颗 LED 与一个独立按键，按下表连接。

模块引脚单片机引脚说明
外接 LED 正极（长脚）GPIO4（经 220Ω 电阻）电阻用于限流，约 5~10mA
外接 LED 负极（短脚）GND共地
按键一端GPIO15使用内部上拉，无需外部电阻
按键另一端GND按下时把 GPIO15 短接到地
板载 LEDLED_BUILTIN（默认 GPIO2）板上已焊好，无需接线

为什么这样接：

  • 为什么 LED 要串 220Ω 电阻？ ESP32 输出 3.3V，LED 压降约 2V，电阻两端约 1.3V，串 220Ω 电流约 6mA，安全又够亮。不串电阻电流可超 20mA，损坏 LED 和引脚。
  • 为什么按键不用外部电阻？ GPIO15 开了内部上拉（INPUT_PULLUP），芯片内部已经帮你接好「默认拉高」的电阻，省一颗 10kΩ。若用 INPUT 浮空，读数会乱跳。
  • 为什么必须共地？ 所有回路（LED、按键）都要回到 ESP32 的 GND，否则电流无回路、信号不可靠。
避坑 GPIO6~GPIO11 被内部 Flash 占用，严禁外接；GPIO0、GPIO2、GPIO15 与启动模式有关，烧录时若外接设备可能导致无法下载，建议优先使用 GPIO4 / GPIO16 / GPIO17 这类安全引脚。

五、完整代码

下面是一个可直接烧录的完整 sketch：板载 LED 持续闪烁，按键按下时点亮外部 LED。Arduino 程序 = setup()（只跑一次）+ loop()（反复执行）。

/* ESP32 GPIO 演示：板载 LED 闪烁 + 按键控制外部 LED（零基础注释版） */
const int ledPin = 4;        // 外部 LED 接 GPIO4（经 220Ω 限流电阻）
const int btnPin = 15;       // 按键接 GPIO15，另一端接 GND（用内部上拉）

void setup() {
  pinMode(LED_BUILTIN, OUTPUT);    // 板载 LED 配成输出
  pinMode(ledPin, OUTPUT);         // 外部 LED 配成输出
  pinMode(btnPin, INPUT_PULLUP);   // 按键配成输入 + 内部上拉：按下为 LOW
  Serial.begin(115200);            // 打开串口，波特率 115200
  Serial.println("GPIO 测试就绪");
}

void loop() {
  // --- 1) 板载 LED 以约 1Hz 闪烁（每 500ms 翻转一次） ---
  digitalWrite(LED_BUILTIN, HIGH);
  delay(500);
  digitalWrite(LED_BUILTIN, LOW);
  delay(500);

  // --- 2) 读按键：按下点亮外部 LED，松开熄灭 ---
  if (digitalRead(btnPin) == LOW) {      // 上拉输入下，LOW = 按下
    digitalWrite(ledPin, HIGH);          // 点亮外部 LED
    Serial.println("按键按下 -> 外部 LED 亮");
  } else {
    digitalWrite(ledPin, LOW);           // 松开熄灭
  }
}

第二个实例：呼吸灯——用 GPIO4 输出「渐变亮度」（LEDC 软 PWM 预告，后续 PWM 课会细讲）：

/* GPIO 变体：呼吸灯（PWM 渐变，可单独新建一个草图烧录） */
const int ledPin = 4;        // LED 接 GPIO4

void setup() {
  ledcSetup(0, 5000, 8);        // 配置通道0：5kHz、8位分辨率(0~255)
  ledcAttachPin(ledPin, 0);     // 把 GPIO4 绑定到通道0
}

void loop() {
  for (int d = 0; d <= 255; d++) {   // 渐亮：占空比 0→255
    ledcWrite(0, d);
    delay(5);
  }
  for (int d = 255; d >= 0; d--) {   // 渐灭：占空比 255→0
    ledcWrite(0, d);
    delay(5);
  }
}

想把按键改成「按一下翻转一次」？在 loop 里检测到 LOW 后加 delay(20) 消抖、再读一次确认，然后用 digitalWrite(ledPin, !digitalRead(ledPin)) 翻转，并等待松开——思路和 STM32 那篇完全一致。

六、代码逐段讲解

第 1 段：setup() 初始化（第 4~9 行）

在做什么： 程序上电后只执行一次：把三个引脚配好方向（两个输出、一个输入上拉），再打开串口。

为什么这么写： Arduino 规定必须把「一次性初始化」放在 setup()：引脚方向必须在用之前确定，否则 digitalWrite 对没配方向的引脚无效；Serial.begin 不写的话串口打印会乱码或没输出。

不写会怎样： 漏掉 pinMode，LED 不亮、按键读数乱跳；漏掉 Serial.begin，串口监视器收不到任何数据。

第 2 段：板载 LED 闪烁（第 12~16 行）

在做什么： loop() 里先把板载 LED 点亮 500ms、熄灭 500ms，再继续往下执行按键逻辑。

为什么这么写： 闪烁是验证「输出通路 + 下载链路」是否正常的快速手段；放在按键逻辑前面，即使按键没接好，也能先确认板子本身在正常工作。

不写会怎样： 只有按键逻辑时，如果灯不亮你分不清是按键问题还是输出问题——先让一个灯规律闪烁是排错的好习惯。

第 3 段：按键读输入（第 19~26 行）

在做什么： digitalRead(btnPin) == LOW 判断按键是否按下（上拉输入下按下=接地=LOW），按下点亮外部 LED 并打印，松开熄灭。

为什么这么写： 按键另一端接 GND + 内部上拉，构成「平时高、按下低」的确定逻辑，digitalRead 结果可信；串口打印让你在电脑上看到按键事件，方便排错。

不写会怎样： 如果用 INPUT 浮空模式，按键没按时引脚悬空，digitalRead 随机返回 HIGH/LOW，外部 LED 会无缘无故闪。

第 4 段：loop() 的循环特性

在做什么： loop() 里的代码执行完会立即从头再执行，无限循环。

为什么这么写： 这是 Arduino 的约定框架，相当于 51/STM32 里的 while(1)；用户只需写「一轮要做的事」，框架负责循环。

不写会怎样： 不需要你写循环——但要意识到每个 delay(500) 都会阻塞 500ms，如果按键按得很快、正好撞在 delay 期间，可能要等半秒才响应，这是入门阶段可以接受的代价。

第 5 段：寄存器 ↔ 驱动 API ↔ Arduino 函数三层对照（教材视角）

ESP32 是「SDK 封装架构」——你写的 Arduino 函数底下，是乐鑫的 ESP-IDF 驱动层 API，再底下才是真刀真枪的硬件寄存器。教材要求看懂这三层关系：

你写的 Arduino 函数底层 ESP-IDF 驱动 API最终操作的硬件寄存器
pinMode(4, OUTPUT)gpio_set_direction(GPIO_NUM_4, GPIO_MODE_OUTPUT)GPIO 使能输出寄存器 + IO_MUX 功能选择位
digitalWrite(4, HIGH)gpio_set_level(GPIO_NUM_4, 1)GPIOn_OUT 输出数据寄存器对应位置 1
digitalRead(15)gpio_get_level(GPIO_NUM_15)GPIOn_IN 输入数据寄存器读位
pinMode(15, INPUT_PULLUP)gpio_set_pull_mode(GPIO_NUM_15, GPIO_PULLUP_ONLY)GPIO 上下拉使能寄存器对应位

为什么这层对照重要：课程设计或面试被问「digitalWrite 到底干了什么」，标准答案就是「框架调 gpio_set_level，它去写 GPIOn_OUT 寄存器」。理解后，遇到 Arduino 函数不够用的场景，你知道可以直接调 ESP-IDF 的 gpio_set_drive_capability 等 API 去拧驱动强度。

七、现象演示说明

  • 现象 1：板载 LED 持续、均匀地以约 1Hz 闪烁，不受按键影响。
  • 现象 2：按住外接按键时，GPIO4 上的外部 LED 点亮；松手即灭。
  • 现象 3：打开串口监视器（115200），每次按下按键会打印一行 “按键按下 -> 外部 LED 亮”。

可量化的验证方法：

  • 数闪烁：用手机秒表数板载 LED 10 次亮灭周期，应为约 10 秒（每次 500ms 亮 + 500ms 灭）。偏差大说明代码或烧录版本不是当前文件。
  • 改参数看变化：把两个 delay(500) 改成 delay(100)，闪烁应明显加快（约 5Hz）；改回 1000 则变慢——验证延时生效。
  • 验证输入：按 10 次按键，串口监视器应恰好打印 10 行 “按键按下” ——若一次打印多行，说明按键抖动，需要在 if 内加 delay(20) 消抖或用 millis() 判断稳定时长。
  • 万用表量电平：GPIO4 输出高时对 GND 约 3.3V、低时接近 0V；GPIO15 松开时约 3.3V、按下时约 0V。

九、课后练习与延伸

练习 1（改引脚）： 把外部 LED 从 GPIO4 改到 GPIO16，按键从 GPIO15 改到 GPIO17。提示：只改代码里 const int ledPin = 4; 和 const int btnPin = 15; 两行，接线同步换，注意 GPIO6-11 不能用。

练习 2（改功能）： 改成「按一下外部 LED 状态翻转、再按再翻」，而不是按住才亮。提示：加 20ms 消抖 + 确认后 digitalWrite(ledPin, !digitalRead(ledPin)) + 等待松开的循环，三段缺一不可。

练习 3（扩展功能）： 用按键控制板载 LED 的闪烁速度（每按一次，delay 在 200/500/1000 之间切换一档）。提示：用一个全局变量记录当前档位，按键有效后改变 delay 值。
