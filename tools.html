在线工具

全部由原生 JavaScript 在浏览器本地实时运算，无后端、无网络请求，计算结果不会上传。

1

进制转换器

二进制 / 十进制 / 十六进制双向实时互转。做寄存器值、地址、初值换算时常用：先选「输入进制」，再输入数值，下面三框同时给出 BIN / DEC / HEX 结果。

说明：仅支持非负整数（0 ~ 0xFFFFFFFF）；十六进制可带 0x 前缀，二进制可带 0b 前缀。

51 延时计算器

按晶振频率与定时器模式自动算出机器周期数和 TH0/TL0 初值（12T 标准 51 内核），并生成可直接粘贴的初始化代码。 用法：先选晶振（串口工程建议 11.0592MHz），再选模式、填延时时间，看下方「机器周期数 / TH0 / TL0」三个结果框即可。

说明：机器周期 = 12 / 晶振频率（12MHz 时正好 1us）；初值 = 计满前要数的机器周期数 = 量程上限 − 目标机器周期数。 模式 1（16 位）最大约 71.1ms（11.0592MHz）/ 65.5ms（12MHz）；模式 2（8 位自动重装）最大约 0.277ms，适合做串口波特率发生器。 注意：模式 1 不会自动重装，进中断后必须重新给 TH0/TL0 赋值，否则每次都从头数 65536 个周期。

串口转换工具

ASCII 字符串与十六进制字节互转（UTF-8 编码，中英文均可），修改任意一侧即时联动。

说明：串口调试助手里勾选「HEX 发送/显示」时就需要它——左边输文本右边自动出 HEX 字节，反过来粘贴 HEX 也能还原成文本。HEX 一侧必须是偶数个十六进制字符。

4

CRC 校验工具

输入 HEX 数据自动计算校验值，支持 CRC-8（单总线/SMBus 常用）与两种 CRC-16 变体（Modbus RTU 帧校验最常用）。
