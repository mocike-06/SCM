位运算与宏定义（单片机核心技能）

系列：C 语言基础 进阶 更新：2026-10-25

单片机编程的「看家本领」：所有寄存器配置、引脚控制、数据拼接拆解都靠位运算。本课把二进制/十六进制、五个位运算符和置位/清零/翻转/读位四个经典技巧讲透，并学会用宏定义让代码像读说明书。

一、本课目标与前置知识

学完本课你能做到：

  • 在二进制与十六进制之间熟练换算，看懂 0xFC、0b11110000 这类写法。
  • 写出「把某位置 1 / 清零 / 翻转 / 读出某位」的代码，并解释每步为什么。
  • 用 #define 定义引脚和常量，写出可读性好的头文件。

需要提前掌握的前置知识：

  • 上一课：变量、数组、for 循环。
  • 会用 在线工具-进制转换器 辅助换算（本课鼓励手算 + 工具互验）。

本课会出现的新名词：二进制、十六进制、位、掩码、按位与/或/异或/取反/移位、宏定义、头文件。

二、基础概念铺垫

1. 二进制、十六进制：计算机只认 0 和 1

生活类比：电灯开关只有「开/关」两种状态，8 个开关排成一排就是 8 位二进制——每一位非 0 即 1。十六进制是把 4 位二进制压缩成 1 个符号（0000~1111 → 0~F），就像把电话号码分段记，写起来短。

一句话定义：单片机里 P1 端口就是 8 个引脚，对应 8 位二进制；0xFC 是十六进制写法，等于二进制 1111 1100，表示 P1.0、P1.1 输出 0（共地接法下这两颗灯亮）。换算方法：每 4 位一组，1111=F、1100=C。

例子：0xFE → 1111 1110（最低位 0）；0b00001111 → 0x0F。练熟 0x01/0x02/0x04/0x08/0x10/0x20/0x40/0x80 这 8 个「单 1」十六进制数，流水灯和寄存器操作就通了一半。

2. 按位与 &：两位都是 1 结果才 1

生活类比：两个安检员一起检查，只有两人都说「通过」才放行。& 常用于「把某些位清零（过滤）」，即掩码。

一句话定义：a & b 逐位比较：都是 1 → 1，否则 → 0。经典口诀「和 1 与，保留原样；和 0 与，必得 0」。

例子：P1 & 0x0F 只保留低 4 位（高 4 位清零）：若 P1=0xAB，结果 0x0B。

3. 按位或 |：一个为 1 结果就 1

生活类比：会议室「有一个人举手就算通过」。

一句话定义：a | b 逐位比较：有一个 1 就是 1。口诀「和 1 或，必得 1；和 0 或，保留原样」，用于把某些位置 1 且不动其他位。

例子：P1 |= 0x01; 把第 0 位置 1，其余位不受影响。

4. 按位异或 ^ 与取反 ~

一句话定义：a ^ b 两位不同才得 1（0^1=1、1^0=1、0^0=0、1^1=0），用于翻转某位：P1 ^= 0x01; 把第 0 位 0 变 1、1 变 0。~a 把每一位取反（0 变 1、1 变 0），常配合 & 做「清零某个位」：P1 &= ~0x01; 把第 0 位清零且不动其他位。

例子：0xF0 ^ 0x0F = 0xFF（全部翻转）；~0x01 = 0xFE。

5. 移位 << >>：把位挪位置

生活类比：8 个开关整排往左挪一格，最右边空出的位补 0。左移 1 位等价「乘 2」，右移 1 位等价「除 2」（无符号数）。

一句话定义：a << n 所有位左移 n 位，右边补 0；a >> n 右移 n 位。流水灯的核心就是 P1 = 0xFE << i; 让唯一一个 0 往左跑。

例子：1 << 3 = 0x08——这就是「第 3 位」的标准写法，寄存器操作到处用。

6. 宏定义 #define：给常量起名字

生活类比：协议里写着「第 3 号协议」，不如直接写「登录协议」——#define LOGIN_PROTOCOL 3 就是给数字起外号，以后代码里写外号，编译器会先把外号替换回数字。

一句话定义：#define 名字 值 是编译前纯文本替换，不是变量！它不占内存、没有类型。单片机里常用于：引脚别名（#define LED P1^0）、常量（#define FOSC 11059200UL）、以及「带参宏」：#define SET_BIT(x, n) ((x) |= (1 << (n)))。

例子：#define LED_PIN P1^0 后写 LED_PIN = 0;；但注意宏参数必须加括号，#define MUL(a,b) a*b 遇到 MUL(1+2, 3) 会变成 1+2*3=7 而不是 9——所以带参宏永远写 ((a)*(b))。

三、原理介绍：为什么改寄存器的某一位，必须靠「与或非」而不是直接赋值

51 的寄存器（TMOD/TCON/SCON…）都是一个字节 8 位、每位各管一件事：比如 TCON 第 4 位=TR0(启动定时器0)、第 5 位=TF0(溢出标志)、第 0 位=IT0……它们挤在同一个字节里共用地址。这就引出了单片机编程最核心的机制问题。

原理 1：为什么绝不能 TCON=0x10 整体赋值

你只想「启动定时器 0」（把第 4 位写成 1）。如果直接 TCON = 0x10;，意思是「把整个字节写成 00010000」——结果第 0、1、2 位(IT0/IE0 等别的功能)被你一并写成了 0，原本配好的外部中断设置全被冲掉。这就是「共享位域」的代价：一个字节是多个功能位合租的房间，你不能整张桌子掀了重摆。必须做到「只动目标那一位、其它七位原封不动」——能做到这点的，就是位运算。

原理 2：& | ~ 怎么做到「只动一位、保住其它位」——掩码机制

关键在于构造一个掩码(mask)：想动第 4 位，就拿一个「只有第 4 位是 1、其它全 0」的数 0x10。然后：

  • 置 1：TCON |= 0x10; —— 和 0x10 做「或」：第 4 位与 1 或必然变 1；其它位与 0 或保持原值不变。
  • 清零：TCON &= ~0x10; —— ~0x10 取反成「第4位0、其它位1」；和它做「与」：第4位与0必清0，其它位与1保持原值。
  • 翻转/读位：^= 翻转；if(TCON & 0x10) 与 0x10 做与，只留下第 4 位看它是不是 1。

本质：「与 0 抹掉、与 1 保留」「或 1 置位、或 0 保留」——掩码就是靠这个特性，把操作范围精确框在某一位上。这就是寄存器操作绕不开位运算的根本原因。

原理 3：宏 #define 不是变量——它是「编译前的纯文本替换」

#define FOSC 11059200UL 在真正编译之前，预处理器就把源码里所有 FOSC 直接换成那个数字——它不占 RAM、没有类型、不做运算。好处是改一处全改：以后换晶振只动一行。带参宏的坑：#define MUL(a,b) a*b 遇到 MUL(1+2,3) 会被原样替换成 1+2*3=7 而不是 (1+2)*3=9——因为它只是文本粘贴、不自动加括号。所以带参宏永远写成 ((a)*(b))，每个参数和整体都套括号。

记忆点：寄存器一个字节8位合租一个房间，整体赋值会冲掉别位；掩码=只有目标位为1的数——置1用|mask、清零用&~mask、翻转用^mask、读位用&mask；&0抹/&1留、|1置/|0留就是机制；宏是编译前纯文本替换、不占内存，带参宏每个参数必须套括号。

四、硬件接线说明

本课用「按键 + 8 颗 LED」演示位运算效果：P1 口接 8 颗共地 LED，P3.2 接一个独立按键（按下接地读到 0）。

模块引脚单片机引脚说明
LED1~LED8 阳极各经 220Ω 电阻接 VCC共地接法，写 0 亮
LED1~LED8 阴极P1.0 ~ P1.7位运算直接作用在 P1 上，现象直观
按键一端P3.2配合按键消抖，按一次触发一次位操作
按键另一端GND按下时 P3.2 读到 0

为什么这样接：P1 整口输出，便于你直接观察 P1 数值变化与 LED 亮灭的对应关系；按键接 P3.2 是因为它是 INT0 外部中断引脚，下一课可无缝升级。

五、完整代码

按一次按键，依次演示：整体移位流水 → 置位 → 清零 → 翻转 → 读位判断，用串口同时打印 P1 值（波特率 9600）。

/* 位运算与宏定义综合演示 */
#include <reg52.h>

sbit KEY = P3^2;                 /* 按键引脚 */

#define LED_ON   0x00            /* 宏：8 颗灯全亮的值 */
#define SET_BIT(x, n)  ((x) |= (1 << (n)))   /* 宏：把 x 的第 n 位置 1 */
#define CLR_BIT(x, n)  ((x) &= ~(1 << (n)))  /* 宏：把 x 的第 n 位清零 */
#define TGL_BIT(x, n)  ((x) ^= (1 << (n)))   /* 宏：把 x 的第 n 位翻转 */

void delay_ms(unsigned int ms) {
    unsigned int i, j;
    for (i = 0; i < ms; i++)
        for (j = 0; j < 120; j++);
}

/* 串口初始化：方式 1，波特率 9600（11.0592MHz） */
void uart_init(void) {
    SCON = 0x50;                 /* 0101 0000：方式 1，允许接收 */
    TMOD |= 0x20;                /* T1 方式 2（8 位自动重装）——只改高 4 位 */
    TH1 = 0xFD;                  /* 波特率初值：256 - (11059200/12/32/9600) */
    TL1 = 0xFD;
    TR1 = 1;                     /* 启动定时器 1 */
}

/* 发送单个字符 */
void uart_putc(unsigned char c) {
    SBUF = c;                    /* 写入发送缓冲 */
    while (!TI);                 /* 等发送完成标志 */
    TI = 0;                      /* 清标志 */
}

/* 把 8 位值按十六进制发送（简化版：只发高 4 位、低 4 位两个字符） */
void uart_hex(unsigned char v) {
    unsigned char h = (v >> 4) & 0x0F;   /* 取高 4 位：右移 4 再与 0x0F */
    unsigned char l = v & 0x0F;          /* 取低 4 位：与 0x0F */
    uart_putc(h < 10 ? h + '0' : h - 10 + 'A');
    uart_putc(l < 10 ? l + '0' : l - 10 + 'A');
}

void main(void) {
    unsigned char led = 0xFE;    /* 初始：最低位亮 */
    uart_init();
    while (1) {
        /* 1) 移位流水：0xFE 左移，唯一一个 0 向右跑 */
        P1 = led;
        uart_hex(P1); uart_putc(' ');
        delay_ms(300);
        led = ((led << 1) | 0x01) & 0xFF;  /* 左移一位，最低位补 1，限制 8 位 */

        /* 2) 按键触发位操作演示：按一次执行一步 */
        if (KEY == 0) {
            delay_ms(20);                /* 消抖 */
            if (KEY == 0) {
                /* 置位：把 P1 第 3 位置 1（对应 LED4 灭） */
                SET_BIT(P1, 3);
                delay_ms(500);
                /* 清零：把 P1 第 3 位清零（LED4 亮） */
                CLR_BIT(P1, 3);
                delay_ms(500);
                /* 翻转：第 3 位再翻一次 */
                TGL_BIT(P1, 3);
                delay_ms(500);
                /* 读位：判断第 7 位 */
                if (P1 & 0x80)
                    uart_putc('1');
                else
                    uart_putc('0');
                while (KEY == 0);        /* 等松开 */
            }
        }
    }
}

第二实例：把位操作封装成「四件套」通用宏。把置 1/清零/翻转/读位写成带参宏，以后任何寄存器、任何引脚都能一行调用——这是库代码的标准写法，重点看每个参数都套了括号：

/* 通用位操作四件套：注意每个参数和整体都套括号 */
#define SET_BIT(r, n)   ((r) |=  (1U << (n)))   /* 把 r 的第 n 位置 1 */
#define CLR_BIT(r, n)   ((r) &= ~(1U << (n)))   /* 把 r 的第 n 位清 0 */
#define TGL_BIT(r, n)   ((r) ^=  (1U << (n)))   /* 把 r 的第 n 位翻转 */
#define READ_BIT(r, n)  (((r) >> (n)) & 1U)      /* 取 r 的第 n 位，返回 0/1 */

void delay_ms(unsigned int t);   /* 复用前面的延时 */

void main(void) {
    unsigned char x = 0x00;
    SET_BIT(x, 0);    /* x=0x01：第0位置1 */
    SET_BIT(x, 3);    /* x=0x09：第3位再置1 */
    CLR_BIT(x, 0);    /* x=0x08：第0位清0 */
    TGL_BIT(x, 3);    /* x=0x00：第3位翻回 */
    P1 = x;           /* 串口/LED 可观察 */
    if (READ_BIT(x, 3))   /* 读第3位是几 */
        P1 = 0xFF;
    else
        P1 = 0x00;
    while (1);
}

为什么值得背下来：以后改 STM32/ESP32 寄存器、写传感器时序，全是这四个宏的组合。坑：1U << (n) 里的 U 表示无整常量、位移不溢出；宏里每个参数必须套括号——否则 SET_BIT(P1, 2+1) 会因不括号算错位移位位置。

六、代码逐段讲解

第一段：宏定义的写法与意义

#define SET_BIT(x, n) ((x) |= (1 << (n))) 是带参宏：调用 SET_BIT(P1, 3) 时编译器原样替换成 ((P1) |= (1 << (3)))。为什么参数全加括号：防止替换后优先级错乱（这是宏的头号坑）；为什么用宏而不是函数：宏无调用开销、不占栈，适合这种一行小操作，Keil 里寄存器位操作几乎都用宏。

第二段：移位流水灯的位运算本质

led = ((led << 1) | 0x01) & 0xFF; 拆开看：led << 1 让唯一的 0 左移；| 0x01 把最低位补回 1（否则左边空出的位会引入 0，灯会越变越多）；& 0xFF 保证结果不超 8 位。少了任何一步，流水效果都会错。

第三段：串口发送里的位拆解

uart_hex 演示了最经典的「拆字节」：v >> 4 把高 4 位移到低 4 位，& 0x0F 把其它位清零，得到高 4 位的值；v & 0x0F 直接取低 4 位。这就是 ADC 数据拆分、定时器初值拆分等所有场合的标准手法，务必背下来。

第四段：按键部分的四件套演示

置位、清零、翻转三次操作同一个第 3 位，现象是 LED4 灭→亮→灭，配合读位判断第 7 位并串口打印。为什么单独写这四行：让你亲眼看到「只动一个位、其它位不动」的效果——按一次键，只有 LED4 变化，其余 7 颗灯保持原状态。

七、现象演示与验证

  • 主循环：唯一亮点从 P1.0 一路跑到 P1.7 后循环（流水灯基础效果）。
  • 按一次按键：LED4（P1.3）依次灭 → 亮 → 灭三次变化，期间其它灯完全不动；串口打印 P1 当前值的十六进制。
  • 串口监视器（9600）：每 300ms 收到一个两位十六进制数，观察与 LED 亮灭对应。

验证方法：

  1. 在串口输出中数一数：流水过程中应看到 FE FD FB F7 EF DF BF 7F 循环，与 0xFE 左移手算结果一致。
  2. 按键演示时盯着 P1 其它 7 颗灯：若它们跟着闪，说明你的位操作写法误伤了其它位（很可能整体赋值了），回去检查。
  3. 把 SET_BIT(P1, 3) 临时改成 P1 = 0x08; 烧录观察：按键后 P1 整体被改成 0x08，其它灯全灭——直观体会整体赋值 vs 位运算的区别。

八、常见报错排查方案

报错现象可能原因解决方法
带参宏展开结果不对（如 MUL(1+2,3)=7）宏参数没加括号，优先级错乱宏内每个参数和整体都加括号：#define MUL(a,b) ((a)*(b))
整体赋值后其它功能失效用 TMOD = 0x20; 这类写法冲掉了其它位一律改位运算：TMOD |= 0x20; / TMOD &= ~0x10;
位运算结果不对 / 想置位却清零了把 &、| 与逻辑 &&、|| 混用位运算是单个 & | ^ ~，逻辑运算是双 && ||；操作寄存器用单的
编译报 lvalue required对常量或表达式直接赋值，如 0x01 |= 0x02;赋值目标必须是变量：P1 |= 0x02; 才对
移位结果溢出 / 灯越变越多移位后没 & 0xFF 限制或没补位8 位操作养成习惯：led = ((led << 1) | 0x01) & 0xFF;

九、课后练习与延伸

练习 1（必做）：手算以下结果并用进制转换器核对：0x55 & 0x0F、0x80 | 0x0F、0xFF ^ 0x0F、1 << 7、0xF0 >> 4。

练习 2：新增一个宏 #define GET_BIT(x, n) (((x) >> (n)) & 1)，用它在代码里读按键所在位 if (GET_BIT(P3, 2) == 0) 替代原来的 KEY == 0。

练习 3（进阶）：写一个函数把 8 位值按「二进制」打印到串口（8 个 0/1 字符），核心就是 for (i = 7; i >= 0; i--) uart_putc((v >> i) & 1 ? '1' : '0');——理解逐位提取。
