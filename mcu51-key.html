独立按键与矩阵键盘

系列：51 单片机 进阶 更新：2026-10-25

高校教材「键盘接口」章节核心。本课解决两个问题：怎么让一次按键只算一次（消抖），怎么用 8 根 IO 读 16 个键（矩阵扫描），并用数码管显示键值完成课表练习「外部中断按键计数」的加强版。

一、本课目标与前置知识

学完本课你能做到：

  • 说清机械按键为什么抖动、延时消抖与状态机消抖的区别，并写出代码。
  • 理解矩阵键盘「行扫描 + 列读取」的原理，写出 4×4 键盘扫描函数。
  • 综合：按键控制数码管/串口输出，完成计数与显示项目。

需要提前掌握的前置知识（对应学习路线阶段 2）：

  • 外部中断：课表练习「按键中断计数」的配套基础。
  • 数码管显示：本课练习需要显示键值。
  • 位运算：行列扫描要用到位操作。

本课会出现的新名词：机械抖动、消抖（延时/状态机）、上拉电阻、矩阵键盘、行列扫描、键值、重键/连按。

二、基础概念铺垫

1. 按键的电路本质：一根「可断开的线」

生活类比：独立按键就像门铃按钮——按下去接通、松手断开。单片机侧看到的是一条信号线的电平变化。

一句话定义：按键一端接 GND、另一端接 IO 口（IO 内部/外部上拉到 VCC）。平时 IO 读到高电平（1）；按下时 IO 被短路到地，读到低电平（0）。所以「读到 0 = 按下」。上拉电阻保证松开时电平确定，不会悬空乱跳。

例子：if (KEY == 0) 就是「检测到按键按下」。

2. 机械抖动：按键不是「瞬间到位」的

生活类比：按下开关时触点不是一次接触好，而是「啪嗒啪嗒」弹几下才稳定——金属簧片的弹性造成约 5~20ms 的反复通断，这就是抖动。

一句话定义：机械抖动会让一次物理按键在电气上表现为「0→1→0→1…」多次跳变，程序如果不处理，按一下会被当成按了好几次（计数狂跳、LED 连闪）。

例子：课表练习「按键计数」如果不消抖，按一次可能计 3~5 次。

3. 两种消抖方案：延时法与状态机法

一句话定义：延时法：检测到低电平后延时 10~20ms（跳过抖动期）再读一次，确认还是低才算按下——简单直观，但延时期间程序被占住。状态机法：用变量记录按键上次状态，只在「上次高 → 本次低」的跳变瞬间计数，配合定时扫描——不阻塞、抗抖好，工程常用。

例子：延时法适合入门演示；状态机法适合「一边扫键盘一边跑显示」的复杂程序。本课两种都给你。

4. 矩阵键盘：8 根线读 16 个键

生活类比：16 个按键排成 4 行 × 4 列，每行每列各拉一根线出来（行列交叉处放按键）。要知道哪个键被按，先「行线发信号、列线听回声」——像点名：喊第 2 行的人，听第几列回应。

一句话定义：矩阵键盘把 16 个键接成 4 行 + 4 列 = 8 根 IO。扫描时让所有行输出低电平，读取列线——某列读到 0 说明该列有键按下；再逐行输出 0、其余行输出 1，配合列值就能定位「第几行第几列」，即唯一键值。

例子：先让全部行=0，读到 P2.6 列=0，说明第 3 列有键；再让第 1 行=0 其余行=1，读 P2.6 仍为 0 → 键在（第 1 行，第 3 列）。

三、原理介绍：一颗按键怎么就不用外接上拉，矩阵又怎么用 8 根线读 16 键

按键本质是「通/断」开关。51 的 IO 内部带弱上拉，所以独立按键一端接 IO、一端接地即可——按下把 IO 拉到 0、松开被内部上拉维持 1。16 键若每键一根 IO 要 16 根，用矩阵 4×4 只要 8 根。

矩阵扫描两遍法：

  1. 粗定位：4 行全部输出 0，读 4 列。全 1=没键；某列 0=该列有键。
  2. 精定位：逐行输出 0（其余行输出 1）再读列，读回列=0 的那行就是行号。
  3. 行号列号齐全，键值 = 行×4 + 列（0~15），再查表映射成 0~9、A~F。

原理 1：为什么按键接 P3 不用外接上拉电阻

回到 IO 口内部结构（见 LED 课）：往引脚写 1 后，内部那个约 30kΩ 弱上拉电阻就把电平托在高。按键另一端接地——松开时没人拉低，内部弱上拉把引脚维持高电平，读到 1；按下时按键把引脚直连 GND，强行拉到 0，读到 0。全程不需要外接上拉。这就是「准双向口当输入前先写 1」的标准动作的日常应用：你初始化时往 P3.2 写过 1，下拉 MOS 已关断，引脚才肯被外部按键自由拉低/松手回弹。若之前把该位写过 0，内部下拉 MOS 死拽着地，按键怎么按都读不到高电平——这是矩阵扫描「列线必须先写 1 准备读」的依据。

原理 2：矩阵扫描两遍法在电路上到底发生了什么

矩阵键盘把 16 个键放在 4 行 × 4 列的交叉点上：每个键一端接行线、一端接列线，按下就把该行列短接。扫描的本质是利用这个短接关系「反推」哪个交叉点被按下：

  • 第一遍找列：所有行输出 0。若某交叉点被按下，那一行的 0 就被短接传到对应列，列线（已写 1、靠内部上拉维持高）被拉低 → 读到该列 0。没键则所有列保持 1。
  • 第二遍找行：改成只有某一行输出 0、其余行输出 1。若刚才那列仍读到 0，说明是「这一行」的 0 通过按下的键传过来的 → 锁定行号；若列变回 1，说明不在这一行，换下一行试。

为什么先全行 0 粗扫一遍：先判断「到底有没有键按下」，没键直接退出、省电省 CPU；再逐行精扫定位。行号列号凑齐就是唯一坐标——16 个键被压缩到 8 根线。

原理 3：为什么要消抖——机械触点的电气现实

物理按键的金属触点在按下/松开瞬间会弹跳几毫秒，电平在 0/1 间抖好几次。不消抖，一次「按」会被读成按下又松开又按下好几遍。延时法：读到 0 后 delay_ms(20) 躲过抖动期，再确认还是 0 才算数；状态机法：只在「上次高→本次低」的跳变沿计数，不阻塞主循环。连按（按住反复触发）靠「等松手」处理，重键（同按两键）扫描结果不定、入门不管。

记忆点：按键一端接地、IO 先写 1 靠内部弱上拉，所以免外接上拉；矩阵=行列交叉点放键、按下把行列短接，先全行0读列找列、再逐行0读列定行，键值=行×4+列；机械触点要抖几毫秒，进 0 后延时 20ms 再确认。

四、硬件接线说明

独立按键：4 个，接 P3.2~P3.5（其中 P3.2 是 INT0，可联动外部中断课）。矩阵键盘：4×4，行接 P2.0~P2.3，列接 P2.4~P2.7。显示用上一课的 4 位数码管（段 P0、位 P2.0~P2.3 会冲突，练习建议分开——本课先用串口输出键值，或用 1 位数码管接 P0 显示）。

模块引脚单片机引脚说明
独立按键 K1~K4 一端P3.2 ~ P3.5内部/外部 10kΩ 上拉
独立按键另一端GND按下读到 0
矩阵行 R1~R4P2.0 ~ P2.3扫描时轮流输出 0
矩阵列 C1~C4P2.4 ~ P2.7读入列状态
数码管（可选）段 P0、位 P2.0~P2.3与矩阵共用 P2 会冲突，二选一或换引脚

为什么这样接：P2 作矩阵是常见教学接法；独立按键接 P3.2~P3.5 顺带把 INT0/INT1 引脚留出，教材的「按键中断计数」练习可直接复用。若要把键值显示到数码管，建议矩阵行/列改接 P1/P3，把 P2 留给位选，避免引脚冲突。

避坑 矩阵键盘行与列接反会导致「键值错位但对不上号」——先接好再统一映射表；仿真里 KEYPAD-SMALL 是现成 4×4 元件，引脚含义看它的数据手册。

五、完整代码

示例 1：独立按键延时消抖 + 计数（串口输出）

/* 独立按键计数：按一次 K1，串口发一次计数值 */
#include <reg52.h>

sbit KEY = P3^2;                 /* 按键接 P3.2（INT0） */

void delay_ms(unsigned int ms) {
    unsigned int i, j;
    for (i = 0; i < ms; i++)
        for (j = 0; j < 120; j++);
}

void uart_init(void) {           /* 9600 @11.0592MHz */
    SCON = 0x50;
    TMOD |= 0x20;
    TH1 = 0xFD;  TL1 = 0xFD;
    TR1 = 1;
}

void uart_putc(unsigned char c) {
    SBUF = c;
    while (!TI); TI = 0;
}

void main(void) {
    unsigned char count = 0;
    uart_init();
    while (1) {
        if (KEY == 0) {          /* 检测到低电平 */
            delay_ms(20);        /* 延时消抖：跳过抖动期 */
            if (KEY == 0) {      /* 再读一次，确认稳定 */
                count++;
                uart_putc('0' + count % 10);  /* 简单显示个位 */
                while (KEY == 0); /* 等待松开，避免连按 */
            }
        }
    }
}

示例 2：4×4 矩阵键盘扫描（返回键值 0~15）

/* 矩阵键盘扫描：P2.0~2.3 行，P2.4~2.7 列 */
#include <reg52.h>

sbit R1 = P2^0; sbit R2 = P2^1;   /* 行 */
sbit R3 = P2^2; sbit R4 = P2^3;
sbit C1 = P2^4; sbit C2 = P2^5;   /* 列 */
sbit C3 = P2^6; sbit C4 = P2^7;

/* 返回 0~15 的键值；无键按下返回 16 */
unsigned char scan_key(void) {
    unsigned char row, col;
    /* 第一步：全部行输出 0，读列。行=P2.0~2.3(低4位)，列=P2.4~2.7(高4位) */
    P2 = 0xF0;                    /* 低4位行=0 输出，高4位列=1 写好准备读入 */
    if ((P2 & 0xF0) == 0xF0)     /* 高4位列全 1 → 无键按下 */
        return 16;
    /* 第二步：逐行输出 0，其余行输出 1，读列 */
    for (row = 0; row < 4; row++) {
        P2 = 0xFF;                /* 先全 1 */
        P2 &= ~(1 << row);        /* 当前行输出 0（位运算清零） */
        for (col = 0; col < 4; col++) {
            if ((P2 & (0x10 << col)) == 0)  /* 该列读到 0 */
                return row * 4 + col;        /* 键值 = 行×4+列 */
        }
    }
    return 16;                    /* 理论到不了这里 */
}

void main(void) {
    unsigned char key;
    while (1) {
        key = scan_key();         /* 不断扫描 */
        if (key != 16) {
            /* 此处把 key 显示到数码管或发串口 */
            /* uart_putc(key < 10 ? '0' + key : 'A' + key - 10); */
        }
    }
}

六、代码逐段讲解

第一段：延时消抖的「三保险」

if (KEY == 0) 第一次读到低 → delay_ms(20) 跳过抖动窗口 → if (KEY == 0) 二次确认 → 处理 → while (KEY == 0) 等松开。为什么需要后两个：光延时一次，抖动尾巴可能还在；不等松开就退出，手指按住期间会反复进入计数——「三保险」缺一不可，这是教材标准写法。

第二段：矩阵扫描第一步的位运算

P2 = 0xF0; 把低 4 位（行）全部输出 0、高 4 位（列）写 1 准备读入——注意 51 准双向口读引脚前必须先往该位写 1。(P2 & 0xF0) == 0xF0 判断列全 1 则无键。为什么先全行 0 再读列：任一键按下都会把该列拉低，一次就能筛掉「没按键」的绝大多数情况，省掉后续逐行扫描的耗时。

第三段：逐行定位与键值编码

P2 &= ~(1 << row); 是位运算「清某一位」的标准式：1 << row 生成第 row 位的 1，取反后与 P2 相与，只把该位清零。0x10 << col 生成列掩码（0x10、0x20、0x40、0x80），读列值。键值 row * 4 + col 是教材惯例编码，方便查表转成数字/字母。

第四段：关于「冲突引脚」的工程思维

示例把矩阵放 P2，位选也常用 P2——引脚不够用是常态，所以本课正文提醒换脚或分时复用。真正的大项目会用 74HC573 锁存器 扩展 IO，这也是下一课的动机。

七、现象演示与验证

  • 示例 1：串口监视器（9600）里，每按一次 K1 输出一个递增数字；快速连按也只加 1 次。
  • 示例 2：按矩阵键盘任意键，串口/数码管显示对应键值；同时按两个键时结果以先扫到的为准。

验证方法：

  1. 删掉 delay_ms(20) 重新烧录，快速按键计数会乱跳——亲手证明消抖的必要。
  2. 在矩阵扫描第二步里打印 row/col 中间值，对照键盘布局验证「行×4+列」映射正确。
  3. 把独立按键改接到 P3.2（INT0），用外部中断实现计数（参考 外部中断教程），体会轮询与中断两种方式。

九、课后练习与延伸

练习 1（必做）：把独立按键计数显示到数码管（复用上一课秒表的显示函数），完成课表练习「按键计数」完整版。

练习 2：给矩阵键盘加键值映射表：0~9 显示数字，10~15 显示 A~F，并在 seg 段码表里补字母段码（A=0x77、b=0x7C、C=0x39、d=0x5E、E=0x79、F=0x71）。

练习 3（进阶）：用状态机法重写独立按键消抖（定时器 10ms 中断扫描，记录上次状态，跳变才计数），对比延时法在「同时跑数码管显示」时谁的显示更流畅。

延伸学习：键盘是「输入」，下一课 蜂鸣器发声 做「输出告警」；想用更少的线驱动更多 IO，学 总线扩展（74HC573）。
