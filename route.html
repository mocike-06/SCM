学习路线

从零基础到物联网实战，共 5 个阶段。建议按顺序学习，每个阶段完成练习项目后再进入下一阶段。

1

阶段 1：前置 C 语言基础

约 2 周

学习重点

  • 变量、数据类型、运算符与流程控制
  • 数组与指针（Keil 中数组操作很常用）
  • 位运算：&、|、^、<<、>>
  • 宏定义 #define 与头文件组织
  • 函数封装：让主函数尽量精简

练习项目

  • LED 流水灯逻辑：用数组 + 移位实现 8 灯花样闪烁
  • 用宏定义引脚，体会可读性提升
  • 写一个软件延时函数并估算误差
避坑提示 新手常把 = 与 == 写混导致条件永远成立； 位运算优先级低于比较运算，务必加括号。C 基础没打牢，后面调 bug 会非常痛苦。
开始学习：C 语言基础 →
2

阶段 2：STC89C52 51 单片机入门

约 4 周

学习内容

  • IO 口：准双向口原理、LED / 按键控制
  • 定时器：模式配置与初值计算（配合延时计算器）
  • 外部中断：INT0 / INT1 触发与优先级
  • 串口通信：UART 收发与上位机联调
  • LCD1602 液晶显示

练习项目

  • 串口收发：电脑发指令控制 LED
  • 定时器计时：数码管显示秒表
  • 外部中断：按键中断计数
避坑提示 晶振选择影响定时器与串口波特率精度，11.0592MHz 是串口调试的黄金频率； 串口乱码大多是波特率不一致或晶振与代码假设不符导致，先查这两项。
开始学习：51 开发环境搭建 →
3

阶段 3：Proteus 仿真

约 2 周

学习内容

  • 原理图绘制：元件放置、连线、电源网络
  • 仿真调试：加载 HEX 文件、单步执行、变量观察
  • 元件库导入：第三方库的安装与使用
  • 虚拟仪器：示波器、串口虚拟终端

练习项目

  • 51 最小系统仿真：LED 闪烁 + 按键
  • 用虚拟串口终端验证串口收发
避坑提示 仿真不运行先查：芯片型号是否选对、晶振是否连接、复位电路是否接好； 元件库缺失时到 Proteus 官方库或社区下载对应版本库文件导入。
开始学习：Proteus 仿真 →
4

阶段 4：STM32 HAL 库开发

约 5 周

学习内容

  • GPIO：CubeMX 配置、点亮 LED、按键输入
  • USART 串口：printf 重定向
  • 定时器 PWM：呼吸灯、舵机调速
  • ADC 模拟采集：多通道电压测量
  • I2C 通信：软件时序 + OLED 屏幕

练习项目

  • 电压采集：电位器分压送串口显示
  • PWM 调光：按键控制 LED 亮度
  • OLED 显示系统信息
避坑提示 时钟配置错误是 STM32 最常见翻车点：外部晶振型号、HSE 频率必须在 CubeMX 里与硬件一致； HAL 库回调函数（如 HAL_GPIO_EXTI_Callback）要在对应中断回调里写业务逻辑，不要在中断服务函数里加耗时操作。
开始学习：Keil MDK 环境搭建 →
5

阶段 5：ESP32 物联网实战

约 4 周

学习内容

  • GPIO：Arduino 框架快速上手
  • WiFi：STA / AP 模式、HTTP 服务器
  • 蓝牙：经典蓝牙 / BLE 串口透传
  • MQTT：接入物联网云平台，发布订阅消息
  • 传感器：DHT11、DS18B20 读取与上报

练习项目

  • 手机远程控制 LED：浏览器访问 Web 页面
  • 温湿度上报：MQTT 上云 + 手机查看
避坑提示 配网失败先检查 WiFi 频段（ESP32 不支持 5GHz）、密码与模块供电； 串口波特率写错会一直输出乱码，Arduino 默认 115200，注意与监视器一致。
开始学习：Arduino IDE 环境搭建 →
学习建议 每个阶段完成「练习项目」后再进入下一阶段；遇到问题先查报错、再查硬件接线，最后才是怀疑代码。 全部完成后可以挑战实训毕设页的完整项目。
